# Creative Studio

## Creative OS no es un gestor de proyectos.

Creative OS es un estudio creativo digital.

Cada usuario entra a su propio estudio.

Dentro del estudio existen distintos proyectos.

Cada proyecto tiene una Mesa de Producción.

La Mesa de Producción reúne todas las conversaciones, documentos, decisiones y avances del proyecto.

El Productor Ejecutivo acompaña al usuario durante todo el proceso.

El usuario nunca navega módulos.

Navega espacios de trabajo.

---

# Principios

El software debe sentirse más cercano a un estudio creativo que a una herramienta administrativa.

Las pantallas representan lugares.

No funciones.

Las personas construyen proyectos.

Creative OS construye estudios.
