# Ecosystem Map

> Este documento representa la arquitectura conceptual del ecosistema.
>
> No describe pantallas.
> No describe funcionalidades.
>
> Describe cómo circula el valor entre todos los agentes que participan en Creative OS.

---

# Principio Fundamental

El centro del ecosistema no es Creative OS.

El centro es una posibilidad.

Una posibilidad puede ser:

- una idea
- un proyecto
- una necesidad
- un problema
- una convocatoria
- una oportunidad
- una conversación
- una comunidad
- una investigación

Todo el ecosistema existe para ayudar a que esa posibilidad encuentre el camino para convertirse en realidad.

---

# Creative OS

Creative OS no produce.

Creative OS no reemplaza.

Creative OS no decide.

Creative OS observa.

Organiza.

Relaciona.

Aprende.

Propone.

Activa.

Creative OS funciona como el sistema nervioso del ecosistema.

# Principio de circulación

El valor nunca termina.

Siempre vuelve al ecosistema.

Cada proyecto genera:

- conocimiento

- relaciones

- aprendizaje

- nuevas oportunidades

- confianza

- comunidad

- información

Toda esa información vuelve a Creative OS.

Creative OS aprende.

Y ayuda a que el siguiente proyecto comience desde un mejor punto.

---

# La misión del ecosistema

No producir más proyectos.

Sino producir mejores relaciones entre las personas capaces de hacerlos realidad.
