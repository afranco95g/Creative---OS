# Creative OS Book

> El documento maestro de Creative OS.
>
> Este libro reúne la visión, los principios, la metodología, la arquitectura y la evolución del sistema operativo para productores creativos.
>
> Todo cambio importante en el producto debe reflejarse aquí antes de implementarse.

---

---

# Filosofía del Book

Este libro no existe para documentar el pasado.

Existe para ayudarnos a tomar mejores decisiones en el futuro.

Cada capítulo debe responder una pregunta concreta.

Cada documento debe poder leerse de forma independiente.

El objetivo no es escribir mucho.

El objetivo es construir un sistema que cualquier persona del equipo pueda comprender y ampliar.
