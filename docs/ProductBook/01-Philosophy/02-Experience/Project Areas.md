# Project Areas

## ¿Por qué existen las Project Areas?

El ProjectGraph es la estructura interna de Creative OS.

Sin embargo, un usuario no piensa en módulos.

Piensa en las diferentes áreas que necesita fortalecer para que su proyecto funcione.

Las Project Areas son la traducción humana del ProjectGraph.

Mientras el sistema organiza información técnica, el usuario construye áreas de trabajo.

---

# Principios

Las Project Areas deben cumplir cinco reglas:

1. Deben ser fáciles de entender.
2. Deben aplicar a cualquier tipo de proyecto.
3. Deben evolucionar con el proyecto.
4. Deben poder producir documentos.
5. Deben servir como guía para la conversación.
# Área 1 — Dirección

La Dirección responde una pregunta:

¿Vale la pena que este proyecto exista?

Aquí el Productor Ejecutivo intenta entender:

- qué se quiere construir
- por qué existe
- para quién existe
- cuál es el problema
- cuál es la oportunidad
- cuál es la visión

No pregunta estos puntos uno por uno.

Los descubre durante la conversación.

Internamente esta área alimenta:

- identidad
- propósito
- problema
- contexto
- comunidad
- objetivo general
- objetivos específicos

# Modelo Universal de Proyecto

## Definición

El Modelo Universal de Proyecto es la forma en que Creative OS organiza cualquier proyecto sin importar su naturaleza.

Puede ser:

- una marca
- una película
- una fundación
- un evento
- una convocatoria
- un producto
- una empresa
- una investigación
- una experiencia cultural

Todos los proyectos tienen una lógica común:

1. nacen de una intención,
2. necesitan dirección,
3. requieren producción,
4. deben generar valor,
5. dependen de personas y recursos,
6. necesitan salir al mundo,
7. deben evolucionar.

Creative OS organiza esa lógica en siete áreas.
# Las 7 Áreas Universales

## 1. Identidad

¿Qué estamos construyendo?

Define el nombre, esencia, descripción, tono, categoría y personalidad del proyecto.

## 2. Dirección

¿Hacia dónde va?

Define propósito, problema, oportunidad, comunidad, objetivos y visión.

## 3. Producción

¿Cómo sucede?

Define actividades, cronograma, operación, tareas, responsables, riesgos y entregables.

## 4. Recursos

¿Qué necesita para existir?

Define presupuesto, costos, ingresos, sostenibilidad, financiación y recursos disponibles.

## 5. Valor

¿Por qué alguien debería involucrarse?

Define propuesta de valor, impacto, beneficios, diferencial, narrativa y razones para apoyar.

## 6. Ecosistema

¿Quién hace posible esto?

Define aliados, equipo, proveedores, mentores, patrocinadores, convocatorias y comunidad ampliada.

## 7. Activación

¿Cómo sale al mundo y cómo evoluciona?

Define comunicación, lanzamiento, canales, medición, aprendizaje, mejora y próximos ciclos.
