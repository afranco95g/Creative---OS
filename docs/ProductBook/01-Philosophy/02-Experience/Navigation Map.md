# Navigation Map

## Filosofía

Creative OS no se navega por módulos.

Se navega por espacios de trabajo.

Cada espacio representa un momento diferente dentro del proceso creativo y productivo.

El usuario nunca debería preguntarse:

"¿Dónde está esta función?"

Siempre debería pensar:

"¿Qué necesito hacer ahora?"

La navegación siempre debe responder esa pregunta.

---

# Nivel 1

## Executive Workspace

Es la pantalla principal del sistema.

Representa el escritorio diario del Productor Ejecutivo.

Aquí el usuario encuentra:

- prioridades del día
- proyectos activos
- tareas pendientes
- decisiones importantes
- recordatorios
- acceso a crear un nuevo proyecto
- acceso a la biblioteca
- acceso futuro a la red

El Workspace nunca muestra demasiada información.

Debe reducir ansiedad.

Debe ayudar a decidir en qué trabajar.

---

# Nivel 2

## Proyecto

Al seleccionar un proyecto, el usuario entra a su espacio operativo.

Este espacio reúne toda la información relacionada con ese proyecto.

No es un chat.

No es un documento.

Es una Mesa de Producción.

---

# Nivel 3

## Mesa de Producción

La Mesa de Producción reúne:

- Dashboard Ejecutivo
- Cronograma
- Tareas
- Documentos
- Diagnóstico
- Productor Ejecutivo

Todo gira alrededor del proyecto activo.

Cambiar de proyecto cambia completamente la Mesa de Producción.

---

# Nivel 4

## Herramientas transversales

Existen espacios que no pertenecen a un proyecto específico.

Actualmente:

- Biblioteca

En el futuro:

- Red
- Configuración
- Plantillas
- Organizaciones
- Equipos
