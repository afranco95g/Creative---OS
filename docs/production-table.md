# Creative OS — Mesa de Producción

## 1. Concepto

La Mesa de Producción es el espacio vivo donde Creative OS muestra todo lo que está construyendo mientras el usuario conversa.

No es un dashboard.
No es una pestaña.
No es un formulario.

Es la mesa de trabajo del Productor Ejecutivo.

---

## 2. Principio central

Mientras el usuario habla, Creative OS produce.

La conversación alimenta el proyecto.
El proyecto alimenta los documentos.
Los documentos revelan vacíos.
Los vacíos generan preguntas.
Las preguntas hacen avanzar el proyecto.
