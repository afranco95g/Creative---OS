# Creative OS - Paquete de investigación cognitiva y biblioteca de casos

Este paquete reúne síntesis en Word y fuentes PDF públicas descargables para investigar cómo debe pensar el Productor Ejecutivo según el contexto.

## Contenido

- `word_docs/`: cuatro documentos de síntesis y trabajo.
- `source_pdfs/`: fuentes institucionales y de investigación descargadas desde sus sitios oficiales.
- `catalog/`: catálogo de fuentes y manifiesto de ingestión.

## Uso recomendado

1. Leer primero `01_modelo_cognitivo_productor_ejecutivo.docx`.
2. Responder `04_cuestionario_investigacion_fundador.docx`.
3. Comparar respuestas con `02_biblioteca_de_casos_y_taxonomia.docx`.
4. Usar `03_executive_review_memo_decision.docx` como base de producto.
5. Ingerir fuentes conservando institución, fecha, URL, licencia y calidad de evidencia.

## Aviso de derechos

Los PDFs se incluyen por ser accesibles públicamente desde fuentes institucionales. Su inclusión no altera sus licencias. Antes de redistribuirlos fuera del equipo o incorporarlos como texto completo a un producto comercial, verifica los términos específicos de cada documento. Para fuentes no descargadas, el catálogo conserva enlaces y metadatos.

## Límites

Este paquete no constituye asesoría legal, financiera o tributaria. Los casos sirven para generar hipótesis y preguntas, no para predecir el éxito de proyectos.
