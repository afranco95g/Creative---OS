# Biblioteca inicial para Creative OS

Esta carpeta reúne una selección inicial de recursos públicos y gratuitos para apoyar el razonamiento del Productor Ejecutivo de Cultura Esta.

## Objetivo

Servir como corpus curado para:

- formulación y estructuración de proyectos;
- emprendimiento cultural;
- costos, precios y presupuestos;
- teoría de cambio, indicadores e impacto;
- sostenibilidad y reporte;
- preparación para convocatorias públicas.

## Contenido incluido como archivo

### 01_formulacion

1. `DNP_MGA_Lineamientos_Conceptuales_2023.pdf`
   - Fuente: Departamento Nacional de Planeación de Colombia.
   - Uso sugerido: formulación, cadena de valor, población objetivo, costos, indicadores y ciclo de proyecto.

2. `DNP_Formulacion_Identificacion_2024.pdf`
   - Fuente: Departamento Nacional de Planeación de Colombia.
   - Uso sugerido: problema u oportunidad, actores, objetivos y alternativas.

3. `MinCulturas_Guia_Practica_Somos_Emprendimiento_Cultural_2023.pdf`
   - Fuente: Ministerio de las Culturas, las Artes y los Saberes de Colombia.
   - Uso sugerido: emprendimiento cultural, propuesta, público, sostenibilidad y fortalecimiento.

4. `MinCulturas_Sistematizacion_de_Experiencias.pdf`
   - Fuente: Ministerio de las Culturas, las Artes y los Saberes de Colombia.
   - Uso sugerido: trayectoria, aprendizajes, evidencia, memoria y evaluación de procesos culturales.

## Catálogo complementario

La carpeta `05_catalogo` contiene recursos recomendados que no se redistribuyen dentro del ZIP. Incluye enlaces oficiales o páginas de descarga, temas, licencia conocida y uso sugerido.

## Recomendaciones de ingestión

1. No cargues todos los PDFs como un único bloque.
2. Extrae por títulos y subtítulos.
3. Conserva metadatos de fuente, institución, fecha y jurisdicción.
4. Etiqueta cada fragmento por tema, tipo de proyecto y etapa.
5. No uses esta biblioteca como asesoría jurídica, tributaria o contable definitiva.
6. Las recomendaciones legales o tributarias deben verificarse con fuentes oficiales vigentes y revisión profesional.

## Licencias y uso

Los documentos incluidos provienen de portales oficiales con descarga pública. Antes de redistribuirlos fuera del uso interno del proyecto, revisa sus avisos legales y condiciones de reutilización. El catálogo marca de forma separada los recursos con licencia abierta conocida.
