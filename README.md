# Creative OS — Sprint 1

Aplicación real Next.js + React + TypeScript + Tailwind para el MVP inicial de Creative OS.

## Incluye

- Chat conversacional simulado
- Proyecto estructurado
- Bitácora Viva
- Documentos
- IPP
- Preparado para OpenAI (`lib/openai.ts`)
- Preparado para Supabase (`lib/supabase.ts`)

## Instalar localmente

```bash
npm install
npm run dev
```

## Deploy en Netlify

Conecta el repositorio desde GitHub.

Configuración recomendada:

```txt
Build command: npm run build
Publish directory: .next
```

Netlify normalmente detecta Next.js automáticamente.
