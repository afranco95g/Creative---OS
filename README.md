# Creative OS — Sprint 1

Aplicación Next.js + React para el MVP inicial de Creative OS.

## Incluye
- Chat conversacional simulado
- Proyecto estructurado
- Bitácora Viva
- Documentos
- IPP

## Deploy en Netlify
Build command: `npm run build`
Publish directory: `.next`

Netlify detecta Next.js automáticamente cuando conectas GitHub.
